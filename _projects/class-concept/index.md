## Overview

A public repository and extension of the **Cosmic Linear Anisotropy Solving System (CLASS)**, modified specifically for use with the **CONCEPT** (COsmological N-body CodE in PyThon) simulation code.

## Purpose

Enables seamless cosmological perturbation integration and initialization of initial conditions and transfer functions directly tailored for CONCEPT N-body simulations, supporting advanced cosmological model testing and high-performance computation.
