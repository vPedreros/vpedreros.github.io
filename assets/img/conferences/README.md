# Conference, Workshop & School Photos

Place images from your conferences, workshops, and seasonal schools here.
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Once placed here, reference them in `_data/conferences.yml` like this:

```yaml
photos:
  - src: "/assets/img/conferences/my-photo.jpg"
    caption: "Presenting at the workshop"
```
